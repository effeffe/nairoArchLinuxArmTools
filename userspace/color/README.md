# Display colour profile

`nairo-tianma-nt36672c.icc` is an ICC v2.4 display profile for the panel,
generated by `make_icc.py` from the downstream panel description
(`qcom,mdss-dsi-panel-hdr-color-primaries`): red (0.640, 0.340), green
(0.310, 0.600), blue (0.160, 0.060), white (0.290, 0.310), 420 nits.

Those are rounded design values, not a measurement of a particular panel.
They describe an sRGB gamut with a cool white point (about 7500-8000 K).
The profile's calibration curves (vcgt) bring the white to D65 by scaling
green to 0.80 and blue to 0.68, and the profile describes the panel after
that correction. Expect warmer whites and about 20% less light.

Install and apply it in the Plasma session:

    install -D -m 644 nairo-tianma-nt36672c.icc ~/.local/share/icc/nairo-tianma-nt36672c.icc
    kscreen-doctor output.DSI-1.iccprofile.$HOME/.local/share/icc/nairo-tianma-nt36672c.icc \
        output.DSI-1.colorProfileSource.ICC

Undo with `kscreen-doctor output.DSI-1.colorProfileSource.sRGB`.
(The display settings module needs the `kscreen` package.)
